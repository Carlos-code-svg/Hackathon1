PLANIFICACIÓN DE IDEAS

1º. La idea, es empezar diseñando una aplicación para corregir el problema de movilidad urbana que hay en nuestra ciudad (en nuestro caso, Albacete).

PASOS A SEGUIR

Para ello, tendremos que realizar los siguientes pasos:
  -Vamos a intentar encontrar plazas de aparcamiento libres.
  -Vamos a compartir información sobre las plazas que queden disponibles.
  -Después, consultaremos en tiempo real los horarios y las rutas de autobuses.
  -Por último, conectaremos con otros ciudadanos que se dirigen a un mismo destino para compartir coche o planificar el viaje.
  
OBJETIVOS DEL PROYECTO

A continuación, pasaremos a detallar los objetivos que hemos de conseguir con esta primera práctica:
   -En primer lugar, ayudaremos a localizar aparcamiento en Albacete.
   -En segundo paso, motivaremos la colaboración ciudadana mediante puntos/recompensas por informar sobre plazas libres.
   -Ahora, compartiremos información de transporte público aunque, al menos, sea simulada.
   -En último lugar, lo que haremos será facilitar que los ciudadanos ahorren tiempo y reduzcan el tráfico lo máximo que se pueda.

ESTRUCTURA DE NUESTRA APLICACIÓN "Albacete ¡Ponte en Marcha!"

-La estructura de nuestra aplicación, será la siguiente:
  1. Una pantalla de inicio, la cual va a incluir el logo de la app, el nombre y un botón que pueda acceder al mapa de aparcamiento.
  2. Dentro del mapa de aparcamiento, incluiremos el número de plazas disponibles, un botón donde el ciudadano pueda marcar la plaza que queda        libre.
  3. Horarios de autobuses, donde incluiremos una lista de todas las líneas y los horarios y paradas que realizarán.
  4. Una movilidad que sea compartida con la ciudadanía, donde se pueda indicar el destino y que aparezca una lista de usuarios que se dirijan al        mismo destino.
  5. Un perfil de usuario, donde aparecerán los puntos acumulados de cada usuario y un historial de colaboraciones.

TECNOLOGÍAS A UTILIZAR EN ESTA PRÁCTICA

-Vamos a implementar el lenguaje Java, que es el que hemos utilizado el año pasado en 1º DAM.
-Como diseño, implementaremos un XML para controlar los layouts.
-En la parte de navegación, usaremos "Navigation Component".
-Para simular los datos, usaremos JSON o Firebase.
-Por último, para el mapeado, "Google Mpas API".
